Adopt the latest Trading and Market Data specifications. This major release removes Forex from the public generated SDK surface and removes the sunset crypto-transfer creation operation, moves generated clock operations into `CalendarApi`, adds international-stock v3 endpoints with facade pagination helpers, and updates generated request, response, enum, nullability, and activity contracts. See the [5.x to 6.0 migration guide](./MIGRATION_V6.md) for required application changes.
